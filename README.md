# SEJF AI — publiczny showroom

Publiczna, statyczna demonstracja roboczej marki SEJF AI i syntetycznego Client Control Room.

## Ważne

- marka i oferta są robocze;
- wszystkie dane dashboardu są syntetyczne;
- publiczny formularz nie zapisuje ani nie wysyła danych;
- wersja produkcyjna wymaga polityki prywatności, bezpiecznego backendu, autoryzacji i security review.

## Lokalnie

```bash
npm ci
npm start
```

Testy:

```bash
npm run check
```
